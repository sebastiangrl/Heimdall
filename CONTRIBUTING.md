# Contributing to Heimdall

Thank you for helping build Heimdall.

## Development

1. Read [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md) and [docs/DATA_CONTRACTS.md](docs/DATA_CONTRACTS.md).
2. Follow phased delivery in [docs/ROADMAP.md](docs/ROADMAP.md) — do not mark features complete without real backend behavior.
3. Run `cargo fmt`, `cargo clippy`, and targeted tests before opening a PR.

## Pull requests

- Keep changes focused.
- Document manual verification steps.
- Never commit secrets, `.env` files, or personal logs.

## Code of conduct

Be respectful and constructive. Harassment is not tolerated.
